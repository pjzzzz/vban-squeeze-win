This is a Windows port of vban-squeeze by Markus Buschhoff. It lets Lyrion Music Server play a VBAN audio stream from VoiceMeeter on any Squeezebox or Squeezelite player.

TL;DR: if you run VoiceMeeter on a Windows PC, this plugin puts that audio on your Squeezebox in another room — no extra hardware, no second audio path.

The original plugin is Linux-only because it depends on the Linux vban_receptor binary. This port ships a native Windows receiver instead (Go, no runtime required).

How it works

VoiceMeeter  --VBAN/UDP-->  Lyrion (Windows)  --PCM-->  Squeezebox
                           vban_url_receptor.exe

The receiver listens for VBAN on UDP, converts 8/16/24/32-bit and float samples to 16-bit stereo PCM, and hands the stream to Lyrion's normal transcoder pipeline. Lyrion then treats it like any other radio stream.

Features

  • Native Windows receiver — no Perl wrapper, no Linux binary
  • Plays on Squeezebox and Squeezelite players
  • Entry in Apps and in the Radio menu; host/port/stream in Settings → Plugins → VBAN
  • Output rate follows the rate Lyrion announces to the player, so player and stream can never disagree
  • Multicast for several independent players (vban://239.255.42.42/Stream1)
  • Silence fill: when the VBAN source goes away the stream keeps running and resumes by itself when audio returns
  • Track info (title/artist) on the player, via VBAN TEXT or Lyrion's CLI
  • Switching between VBAN and a normal radio stream works without restarting Lyrion

Requirements

  • Lyrion Music Server: Windows, 7.9 or newer (tested with 9.1.1)
  • VBAN sender: VoiceMeeter Banana / Potato / VoiceMeeter 8
  • Player: any Squeezebox or Squeezelite player that supports raw PCM
  • Network: inbound UDP 6980 on the Lyrion host

Installation

1. Add this repository under Settings → Plugins → Additional Repositories:

https://raw.githubusercontent.com/pjzzzz/vban-squeeze-win/main/vban.xml

2. Install VBAN from the plugin list and restart Lyrion.

3. Allow inbound UDP 6980 (elevated PowerShell):

New-NetFirewallRule -DisplayName 'VBAN receptor (UDP 6980)' -Direction Inbound -Protocol UDP -LocalPort 6980 -Action Allow -Profile Any

Manual installation from the zip is described in the README. Direct download: github.com/pjzzzz/vban-squeeze-win/releases/latest

VoiceMeeter setup

  • VBAN button (top right) → Outgoing Streams → pick the bus you want
  • IP address: the Lyrion server
  • Sample rate: the same value as the VoiceMeeter engine (menu → System Settings → Sample Rate)
  • Channels: 2 · Format: PCM 16 bits · Stream name: Stream1
  • Switch the stream On and VBAN On

Then play this URL on a player (Radio → Play from URL, or add it as a favourite):

vban://<sender-ip>/Stream1
vban://192.168.178.79/Stream1

One important gotcha: sample rates. VoiceMeeter's ASIO driver runs at the engine rate. The program that feeds VoiceMeeter must output that same rate, otherwise VoiceMeeter converts it internally and the audio can come out roughly 8.8% too fast and too high (48000 vs 44100). If that happens, set the source output rate to the engine rate. For MediaMonkey 5: Tools → Options → Output Plug-ins → ASIO output → Configure → Sample rate 48000 (when the engine is 48000).

Track info

The receiver understands VBAN TEXT and shows the title on the player. Two ways to feed it:

  • tools/smtc-sendtext.ps1 (included): reads the Windows "now playing" information and sends VBAN TEXT. Works with MediaMonkey, Spotify, browsers and other players that report to the Windows media controls.
  • A small companion add-on for MediaMonkey 5 can push the title through Lyrion's CLI (vban title) and needs no extra process: mm5-addon source | direct .mmip download.

Multiple players

  • Synced players share one stream: no extra configuration.
  • Independent players: send a second VoiceMeeter stream on another port (vban://<sender-ip>:6981/Stream2), or use multicast (vban://239.255.42.42/Stream1) with IGMP snooping enabled on the switch.

Troubleshooting (quick)

  • Silence and a pipeline error in server.log — firewall (UDP 6980) or the VoiceMeeter stream is Off.
  • "Buffering... 0 / 153600" and "Read to end of file or pipe" — a stale vban_url_receptor.exe still owns the port; end it with Get-Process vban_url_receptor | Stop-Process and play again.
  • Audio too fast or too high — check the sample-rate gotcha above.
  • Plugin not in the list — install.xml must be in Cache\InstalledPlugins\Plugins\VBAN\; restart Lyrion.

Diagnostics

The receiver writes C:\ProgramData\Lyrion\vban-stats-Stream1.txt once per second:

inputRate=47938.1
ratio=1.0884
targetRate=44100
headerRate=48000

inputRate is what arrives, targetRate is what the player gets, ratio is the conversion between them. If targetRate and the player's rate differ, the installation is outdated (usually an old custom-convert.conf).
